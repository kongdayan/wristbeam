**Garmin → Mac → Garmin Connect. Без приложения на телефоне между ними.**

Я уже сижу за Mac, часы уже на руке, но для синхронизации нужно снова доставать телефон и открывать приложение. Захотелось убрать этот лишний шаг — так появился WristBeam. Часы подключаются к Mac напрямую по Bluetooth, а данные тренировок и здоровья синхронизируются с Garmin Connect.

- **Дайте телефону выходной.** Передавайте файлы тренировок и здоровья с поддерживаемых часов Garmin через Mac в Garmin Connect China или Global.
- **Ваш заряд — в строке меню.** Пульс, Body Battery, стресс, шаги и другие показатели доступны в строке меню, плавающей панели и на графиках за день.
- **Пусть ИИ узнает, как вы себя чувствуете.** Подключите синхронизированные показатели к ИИ-ассистенту через MCP и спросите: «Как я спал прошлой ночью?» Для собственных инструментов есть HTTP/HTTPS API, Python SDK и вебхуки.

Ваш ИИ уже считает токены. Теперь он может поинтересоваться и вашим запасом сил.

## Возможности

- Компактные объёмные карточки с временем обновления рядом с заголовком. Настройка сетки и основных показателей в одной панели; вся панель, выбранные карточки или одно значение экспортируются в светлом или тёмном оформлении для копирования, сохранения и системного обмена.
- Независимый выбор показателей для строки меню, панели и дашборда; группы, поиск, перетаскивание, размер текста и расположение.
- Суточные кривые, интервальные столбцы, выбор даты и времени, значения под курсором и исходные записи. Пропуски остаются пустыми.
- Инструкция по Garmin Bluetooth, постоянная очередь исходных FIT, устранение повторов и облачная синхронизация.
- Светлая／тёмная／системная тема. Интерфейс приложения — китайский и английский; обновление требует подтверждения.

Интеграция для разработчиков: MCP только для чтения, HTTP/HTTPS API, Bearer-ключ, подписанные Webhook, Python SDK и мост stdio. [Документация API](docs/developer/API.md). По умолчанию отключена.

## Поддержка устройств

Сейчас поддерживаются часы **Garmin**; проверенные модели указаны ниже. Поддержку других брендов и устройств можно добавить в будущем.

| Часы | Текущие показатели | Исходные FIT＋China | Солнечные записи | Статус |
| --- | --- | --- | --- | --- |
| Instinct 2 Solar | ✓ | ✓ | ✓ | Проверено на устройстве |
| Instinct 2 / 2S / 2X | Не проверено | Не проверено | Зависит от модели | Ждём отчётов |
| fēnix / epix / Forerunner | Не проверено | Не проверено | Зависит от модели | Ждём отчётов |
| Venu / vívoactive и другие | Не проверено | Не проверено | Зависит от модели | Ждём отчётов |

Поддержка зависит от прошивки и доступных служб. Совместимость всей серии не предполагается. [Матрица и отчёты](docs/DEVICES.md).

## Какие данные доступны

| Показатель | Источник | Отображение |
| --- | --- | --- |
| Пульс, Body Battery, стресс | Уведомления Garmin＋суточные облачные записи | Текущее значение, суточные кривые |
| Шаги | Bluetooth＋облако | Итог дня, прирост по интервалам |
| Частота дыхания, SpO₂ | Измерения часов／облако | Значения, суточная динамика |
| Интервалы RR | Bluetooth | Миллисекунды; не ночная оценка HRV |
| Ночной HRV | Облачные записи сна | Среднее за ночь и 7 дней, статус, базовый диапазон и график; пропуски не заполняются |
| Батарея часов | Garmin Bluetooth | Значок и процент заряда рядом с состоянием устройства; уведомления и периодическое обновление |
| Калории, этажи, минуты интенсивности | Поля часов／облака | Итоги дня, некоторые интервалы |
| Пульс в покое, длительность сна, сводки восстановления | Суточная облачная сводка | Итоги и связанные графики |
| Солнечная интенсивность | Достоверные поминутные записи облака | Кривая от 0 до 24 часов |
| Длительность освещения／солнечной зарядки | Оценка по достоверным минутам | Явно обозначенная оценка |
| FIT активности и здоровья | Исходные файлы часов | Хранение на Mac, отправка в облако |

В каталоге **60 показателей здоровья и одно поле состояния устройства**. Видны только показатели с полученными достоверными данными; доступность зависит от часов. [Полный список и проверка](docs/METRICS.md).

## Установка

| Mac | Пакет |
| --- | --- |
| Apple Silicon | [arm64](https://github.com/kongdayan/wristbeam/releases/latest/download/WristBeam-macOS-arm64.zip) |
| Intel | [x86_64](https://github.com/kongdayan/wristbeam/releases/latest/download/WristBeam-macOS-x86_64.zip) |
| Обе архитектуры | [Universal](https://github.com/kongdayan/wristbeam/releases/latest/download/WristBeam-macOS-universal.zip) |

Нужна macOS 13+. Распакуйте приложение и перенесите в доступную для записи папку Applications. В разделе «Устройства → Подключение» подготовьте часы с отключённой трансляцией пульса, затем нажмите кнопку подключения и разрешите Bluetooth. Выберите China／Global в аккаунте устройства, войдите на официальной странице Garmin и выберите ручную или автоматическую загрузку в истории синхронизации. Автоподключение при запуске выключено по умолчанию; его можно включить после сопряжения.

Подпись ad hoc, без нотариального заверения Apple. Реальные загрузки Global и другие прошивки не проверены. Шифрование уровня приложения, native MLR / CoreTransfer и виджеты рабочего стола не поддерживаются. Во время сна Mac мгновенная синхронизация невозможна. [Область проверки](VERIFICATION.md).
